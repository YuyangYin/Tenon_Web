# Tenon_Web

Project website for **Tenon: Planning, Generating, and Assembling Composable 3D Worlds**.

Open `index.html` in a browser or serve the repository root as a static site. It includes the paper figures and the first two examples from `CVPR-demo-maps-v9-60fps.mp4` at their original resolution and frame rate.
